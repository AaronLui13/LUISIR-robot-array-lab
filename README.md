# 機械人倉庫：2D Array 任務

Lui Sir 的獨立高中 ICT 遊戲網站。八課、00–17 共 18 關，以同一個倉庫操作主線學習二維陣列：

**理解任務 → 預測 → 組合指令 → 觀察執行 → 解釋及修正**

學生拖動的是指令卡；貨量由指令讀寫。每格數字代表貨量，0 代表空格；行、列索引由 0 開始。除 17 的三項連續工作外，每次任務及重試重設貨架。

## 網站

[開啟機械人倉庫](https://aaronlui13.github.io/LUISIR-robot-array-lab/)

- 繁體中文配合英文 ICT 詞彙、逐步執行、連續播放、撤銷、重設及執行紀錄。
- 提供補完 `?` 的任務骨架，以及從空白工作區自由組合指令卡。
- 可拖拉排序，也可點選加入、使用上下移和縮排按鈕，支援鍵盤和觸控。
- 可展開帶註解的 Python 對照；這是指令說明，不是任意 Python 執行環境。
- 新資料測試檢查方法是否可重用；完成概念題後儲存裝置本機任務章。
- 所有關卡供教師直接選用；指令卡庫按所選課題逐步增加。
- 不限時、重試不扣分、無音效、無學生帳戶、無分析追蹤、無伺服器資料儲存。

## 開發與驗證

Node.js 22.13.0 或以上：

```sh
npm ci
npm run dev
npm test
npm run lint
```

預覽網址由開發伺服器輸出。`npm test` 先產生完全靜態的 `dist/`，再執行 Node 規則測試；`npm run lint` 執行 ESLint。所有網站資源採用相對路徑，可放在 GitHub Pages 子路徑。

GitHub Actions 在推送 `main` 或手動啟動後，安裝鎖定依賴、檢查程式、執行測試並發布 `dist/`。本網站有獨立的儲存庫與發布流程，不改動原有 ICT Game Lab。
