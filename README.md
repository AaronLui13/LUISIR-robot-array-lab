# 機械人倉庫：2D Array 任務

Lui Sir 的獨立高中 ICT 遊戲網站。八課、00–17 共 18 關，以同一個倉庫操作主線學習二維陣列：

**理解任務 → 預測 → 組合指令 → 觀察執行 → 解釋及修正**

學生拖動的是指令卡；貨量由指令讀寫。每格數字代表貨量，0 代表空格；行、列索引由 0 開始。除 17 的三項連續工作外，每次任務及重試重設貨架。

## 開發與驗證

Node.js 22.13.0 或以上：

```sh
npm ci
npm run dev
npm test
npm run lint
```

預覽網址由開發伺服器輸出。`npm test` 先產生完全靜態的 `dist/`，再執行 Node 規則測試；`npm run lint` 執行 ESLint。所有網站資源採用相對路徑，可放在 GitHub Pages 子路徑。

GitHub Actions 在推送 `main` 或手動啟動後，安裝鎖定依賴、檢查程式、執行測試並發布 `dist/`。本網站有獨立的儲存庫與發布流程，不改動原有 ICT Game Lab。

### 與課堂筆記銜接

- 每關連結對應 Notion 章節，統一使用變量、嵌套循環、遍歷、行／列索引及元素值。
- 遊戲採用 0-based 索引及不包括結束值的循環；筆記的 1-based、包括兩端示範須按題目定義轉換。
- 填空同時接受 DIV／MOD 與 //／%，以及 = 與 == 相等比較；Python 對照會轉回 Python 符號。
- 搜尋卡「結束本次任務 / Stop」不回傳位置；輸出、return 與 break 的分別在指令對照說明。
- 第 07 關結果是索引編號表，0 是有效索引；第 16 關補零加總不等於只取有效元素求平均。

### Blockly 與自行輸入

- 頁面上方固定顯示「積木 Blockly／自行輸入」切換，預設積木模式，選擇在此裝置保存。
- Blockly 提供數值／變量選單、算式／條件、陣列元素及指令積木；可按「找下一個空格」定位未完成欄位。兩種模式共用原有指令解譯器及評分，沒有執行任意 JavaScript 或 Python。
- 切換、重新載入及關卡切換會保留草稿。未連接積木亦保留；積木模式執行前會要求接好或刪除。
- 自行輸入維持卡片內的算式欄位；未能解析的原算式會完整保留為文字積木，縮排錯誤則提示先修正。
- Blockly 13.3.0 固定版本隨網站提供，沒有執行時 CDN 依賴。其 Apache-2.0 授權隨部署保存在 `vendor/Blockly-LICENSE`。`npm run dev` 及 `npm run build` 自動準備所需檔案。
