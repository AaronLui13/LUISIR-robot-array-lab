# 機械人倉庫設計紀錄

## 已實作的操作主線

桌面採用貨架、指令工作區、任務工作單三欄，下方顯示執行紀錄。手機依序排列，課程地圖可展開。倉庫顯示零起始索引、目前讀取／寫入位置、走訪次數和選取標記。座標變換保留原表，並在新表追蹤目的位置；C 固定橙色。

每關先輸入預測、點選要求的位置，再鎖定預測。預測不正確不阻止學習；正確預測可獲額外標示。學生可修改每張卡的參數、排序、縮排或加入新卡。初段保留較完整骨架，後段改為補上關鍵公式、邊界、累加及搜尋條件。排卡練習提供逆序的完整卡片，學生以排序和縮排重建方法；自由編排從空白開始，過關後亦可選擇再自行組合。

縮排定義重複／如果的巢狀結構。支援讀取、寫入、輸出、重複、檢查、設定／加總／暫存、條件、位置輸出、停止、新表及目的位置寫入。`rows` 和 `cols` 是由資料推導的只讀尺寸；整除 `//`、餘數 `%`、比較與 `and`／`or` 可在欄位內組合。布林運算與連鎖比較均支援短路求值；餘數使用 Python 的除數符號規則。預先產生不可互相影響的執行快照，逐步呈現或按慢／中／快（1000／600／250ms）播放一步；撤銷還原貨架、變數、輸出與走訪紀錄。

遇到未初始化變數、無效算式、索引越界、錯誤縮排或過多步驟，記錄具體原因並可立即重試。執行器不使用 eval，不執行學生 JavaScript；每次最多 4000 步，新表每個維度最多 10 格。Python 面板是語法對照，`process` 是遊戲檢查標記，`return` 需位於函數內。

## 判定與回饋

- 純函數以獨立計算的目標核對結果、來源保持不變、指定處理次數及走訪次序。
- 搜尋第一個要在找到後停止，不得繼續檢查其他格。找不到要輸出「找不到」，每次執行重新初始化。
- 遍歷、計數、搜尋、索引、交換、區域及區塊題另用數值或尺寸變更的資料檢查方法；17 也測試同值情況。
- 提示逐步指出觀察現象、檢查範圍／縮排／初始化，最後顯示一張關鍵卡的參數，並保留其餘操作給學生。
- 正確執行後答一條概念題。含變式的任務需要完成各變式才顯示完整任務章；07、08、17 通過自動雙資料驗證即記錄兩組通過。
- 任務章、預測獎勵及各關／變式草稿只寫入 `localStorage`，使用不同鍵保存。草稿包含編排方式、卡片、預測、鎖定狀態及指定位置；重新開頁回到上次關卡，從原始貨架重建執行，不保存播放快照。儲存內容有版本及結構驗證，壞掉的草稿回到初始骨架。儲存不可用時遊戲仍可進行；沒有排行榜或網路資料回傳。

## 課堂使用

八課開始前玩 00–03。每課以一個短任務引出問題，講解後重試並查看有註解的偽代碼／Python，結課時完成變式。八課後以 17 檢驗獨立整合。教師可直接跳到任何關卡，不受前關完成度限制。每個短任務預期少於十分鐘，綜合題可按課堂安排延長。

## 範圍說明

目前自由編寫指令參數與算式，並提供空白指令工作區；沒有任意 Python 編輯器、Python 執行沙箱或教師集中管理平台。音效未加入，網站保持靜音。沒有學生帳戶、分析工具、外部字型或第三方圖片。

## 索引對照與回饋

07 的答案及完成範圍由當前列數計算。07／08 的互動示範保留同一格的身份，展示逐行展開與還原；示範的地址及一維標籤可一起切換為從 0 或 1 開始，任務本身維持從 0 開始。公式及代入步驟需自行展開。動畫尊重減少動態效果設定。

來源表使用 current 高亮，結果表使用 destination 高亮。工作區內的快照讓學生毋須回捲整張頁面才看到目前資料。位置輸出對應 print／OUTPUT 並繼續執行，與停止卡分開。概念題選錯後顯示該概念的具體解釋；提示依學習內容提供，不依自由編排後可能失效的卡片編號。

## ROBOT–01 動畫

機械人是目前讀寫位置的視覺游標，並非陣列內的一件貨物。待命時以較淡外觀停在左上角；讀取或巡查時移到來源格，寫入時提示舊值與新值，複製資料時顯示來源到目的格的資料移動。工作區的小機械人及最新輸出讓小螢幕也能看到回饋。

動畫事件由前後執行快照的讀取、走訪、寫入、輸出紀錄推導，迴圈變數更新不假裝成一次讀取。撤銷、重設和切關清理舊特效。慶祝只在結果正確並答對概念題時播放，區分完成單一變式與整個任務。效果不阻塞按鈕，也不加入計時扣分或聲音。

使用瀏覽器原生動畫與內嵌 SVG，沒有新增外部圖片、追蹤或執行時依賴。動畫開關儲存在裝置本機，系統要求減少動態效果時使用靜態畫面。
